# Personal Portfolio Website

An interactive personal portfolio website built with HTML, CSS, and JavaScript to showcase my profile, skills, and featured projects.

> **Live Demo:** [4kromm.github.io/portofolio](https://4kromm.github.io/portofolio/)

---

## Tech Stack

| Category | Technology |
| :--- | :--- |
| **Frontend** | HTML5, CSS3, JavaScript (ES6+) |
| **Styling** | Custom CSS / Tailwind CSS |
| **Hosting** | GitHub Pages |

---

## Key Features

- **Responsive Design:** Optimized layout for mobile, tablet, and desktop viewports.
- **Modern UI/UX:** Clean, dark-themed, and intuitive visual layout.
- **Interactive Components:** Smooth navigation, project modals, and dynamic elements.
